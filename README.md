# Simple Python Calculator

This project contains a small Python calculator with basic arithmetic functions.

## Files
- `calculator.py` - defines `add()` and `subtract()`
- `main.py` - demonstrates using the calculator

## Run
```bash
python main.py
```

## Example output
```text
Addition: 10 + 4 = 14
Subtraction: 10 - 4 = 6
```
