# Simple Python Calculator

This project contains a small Python calculator with basic arithmetic functions.

## Files
- `calculator.py` - defines `add()`, `subtract()`, and `multiply()`
- `main.py` - demonstrates using the calculator

## Functions

### add(a, b)
Returns the sum of two numbers.

### subtract(a, b)
Returns the difference between two numbers.

### multiply(a, b)
Returns the product of two numbers.

## Run
```bash
python main.py
```

## Example output
```text
Addition: 10 + 4 = 14
Subtraction: 10 - 4 = 6
Multiplication: 10 * 4 = 40
```

## Example usage
```python
from calculator import multiply

result = multiply(4, 5)
print(result)  # 20
```
